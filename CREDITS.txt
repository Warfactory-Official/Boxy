Boxy - Credits

Boxy is a native NeoForge 1.21.1 addon providing server LOD streaming and distant entity rendering.

Voxy - MCRcortex and multiversion/backport contributors
https://modrinth.com/mod/voxy
The separately installed LOD engine. Voxy code/assets are not included in Boxy.

Voxy Server Side
https://modrinth.com/mod/voxy-server-side
The original server-to-client terrain streaming addon underlying Boxy's VSS implementation.

Sodium / CaffeineMC
https://modrinth.com/mod/sodium
Native renderer dependency and configuration API.

Iris
